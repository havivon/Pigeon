# Pigeon

A colourful SMS app for Android, in Hebrew and English, meant to replace Google Messages /
Samsung Messages as the default SMS app.

Scope: send and receive SMS only. No MMS, no RCS. No internet permission: nothing leaves the phone.

Status: design approved on sample data (screens and widgets); SMS access is the next stage.
See [docs/research.md](docs/research.md) for the feature research and decisions.

Design shots of the real screens: `gradlew :app:recordPaparazziDebug` → `app/src/test/snapshots/images/`.
